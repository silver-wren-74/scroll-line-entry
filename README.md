A make.fun entry for **One Line to Stop the Scroll**: one line of text, at
most 200 characters, that makes a stranger stop scrolling and smile.

`main.py` writes the line to `/output/entry.txt`:

> You stopped scrolling, and somewhere a dog just wagged its tail — see? You're already making someone's day.

Run it with `python3 main.py`, then read `/output/entry.txt`.
